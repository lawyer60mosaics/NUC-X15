# Aurora Luxury Precision Control Center

## 设计定位

界面以桌面硬件控制中心为原型，保留未来科技白色电竞骨架，并融入克制、精密的法式奢华视觉语言。设计不使用第三方品牌 Logo，也不复制具体产品造型；高级感主要来自象牙白层次、经典橙色操作色、暖灰边界、深棕文字、金属固定细节与严格留白。

核心气质：**奢华科技、精密控制、克制电竞**。

## 信息架构

```text
┌──────────────┬───────────────────────────────────────────────────────┐
│ AURORA       │ 页面标题                  系统状态 · 电源 · EN / 中文 │
│              ├───────────────────────────────────────────────────────┤
│ 控制中心     │ 风扇主视觉                 │ CPU / GPU 设备状态         │
│ 系统监控     ├────────────────────────────┼────────────────────────────┤
│ 系统设置     │ 风扇阈值                   │ 温度趋势                   │
│              ├────────────────────────────┤                            │
│              │ 静音 / 平衡 / 性能         │                            │
└──────────────┴────────────────────────────┴────────────────────────────┘
```

配置页采用双列分组：

- 左列：界面语言、默认页面、昼夜主题、字号、紧凑模式与模块可见性。
- 右列：默认场景、切换确认、操作历史、灯光恢复。
- 底部：恢复默认设置，作为独立高风险操作区域。

监控页采用“看门狗概览 → 实时遥测与操作记录 → 内核诊断与终端日志”的纵向逻辑，当前事件与历史累计严格分离。

## 边界系统

1. 左侧导航与主工作区之间使用清晰的 `1px` 暖灰竖线。
2. 顶栏底部使用 `1px` 暖灰边界和轻微内高光。
3. 普通卡片使用 `1px` 暖灰描边、`14px` 圆角、低强度外投影与白色内描边。
4. 重要卡片增加内层轮廓；风扇主视觉使用橙色外边界、柔和外光和虚线式内缝线。
5. 风扇容器四角使用银色径向结构表现精密固定件，不使用真实螺丝贴图。
6. 设备状态每行独立封闭，CPU 使用橙色左边，GPU 使用蓝紫色左边。
7. 选中态统一为橙色描边、浅橙背景、柔和外光；普通状态保持低对比暖灰。
8. 所有圆角控制在 `8–14px`，主容器不超过 `18px`。

## 组件规则

### 风扇主视觉

- 独立双层容器，视觉中心保持冷蓝紫灯环。
- 左侧仅显示控制方式，右侧仅显示 CPU / GPU 温度。
- 中心数字表示风扇输出上限，不把装饰信息误当真实 RPM。
- 动效仅用于风扇叶片；尊重系统 `prefers-reduced-motion`。

### 风扇阈值

- 只呈现项目已有的 CPU / GPU 共享上限功能。
- 滑块轨道为暖灰，拇指使用经典橙色。
- 上限未启用时保持清晰的禁用语义，不增加虚构通道或曲线点。

### 设备状态与趋势

- CPU / GPU 各自独立一行并有分割边界。
- 状态使用文字与边界共同表达，不能只依赖颜色。
- CPU 趋势使用橙色，GPU 趋势使用低饱和蓝紫色。

### 场景模式

- 静音、平衡、性能三种现有场景等宽排列。
- 选中场景使用实心橙色与白字。
- 场景切换自动同步并锁定相应功耗配置，不要求用户额外选择 PL1 / PL2。

### 配置页

- 相近设置组合在完整封闭卡片中，避免零散控制项视觉粘连。
- 语言切换覆盖导航、页面标题、表单、状态、确认框与操作记录。
- 大字号模式下，说明文字改为纵向排版并允许内容区滚动，不截断内容。

### 系统监控与看门狗

- “当前看门狗事件”只统计最近两分钟内真实的警告、错误或重载事件。
- 正常心跳、哨兵启动/清理记录不计为异常。
- 历史日志数量不能污染当前健康状态。
- 诊断子卡片沿用奶油白与暖灰边界，避免遗留黑色卡片破坏主题。

## 可访问性与响应式

- 主要控件采用约 `20px` 的可读字号等级；说明文字允许略小但保持高对比。
- 键盘焦点、悬停、按下、选中与禁用状态均需可辨认。
- `≥ 1180px` 使用双列控制台；较窄屏幕折叠为单列。
- `≤ 820px` 左侧导航收窄为图标栏。
- 内容区独立滚动，任何页面不得产生横向溢出。
