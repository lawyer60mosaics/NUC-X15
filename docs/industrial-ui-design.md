# Intel NUC Software Studio 工业界面

版本 0.1.6，2026-10-26。

## 范围与方向

使用 `ui-ux-pro-max` 的设计系统与可访问性检索，采用高对比、稳定交互、清晰焦点和一致对齐的规范。
检索中营销网站的横向滚动、CTA、落地页结构不适用于本项目。实现继续使用原版 WPF / Prism，
主界面保持上方“系统配置 / 性能调优”、下方“显示设置 / 键盘 / 光条”以及底部两个入口。
不增加新的硬件操作或重新实现厂商服务。

## 主界面与原版控件

`Themes/Industrial.xaml` 提供同名颜色与画刷资源。`IndustrialTheme` 在运行时为原版命名样式
派生工业样式，覆盖字体、按钮、开关、下拉框和滑块把手的外观。
已创建的控件通过样式对象映射更新；后续创建的控件通过资源查找和 Loaded 处理更新。

保留原版 Style 的继承、绑定和交互约定：

- 开关保留 `Label` / `TextBorder` / `ToggleBorder` 名称和 `IsChecked` 状态。
- 下拉框保留 `PART_Popup` 和 `PART_EditableTextBox`，支持原有可编辑模式、选项模板和选择绑定。
- 保留 Slider 的值、范围、步进和键盘命令，以及原版按钮命令。
- 不改写 `IsEnabled` / `Visibility` / 选中状态，不绕过设备能力或 EC 互斥限制。
- 面板边框和标题分隔线使用同一窗口的非交互绘制层。其层级低于 EC 页面/遮罩，避免装饰线
  穿透到 EC 页面；不重新挂接原版 Window.Content 或 Prism 区域。
- 标题栏图标继续使用原来的图标字体和事件，X 隐藏到托盘、托盘退出与自启动行为保持。

主界面保留原生网格及原生缩放。EC 页面单独补充响应式：900 DIP 以下改为单列操作和两列读数；
宽窗口恢复双列操作和四列读数，面板填满剩余高度。内容超出时使用深色滚动条，交还控制按钮可滚动到达。

- 载入原版五个主页 BAML 视图，使用空模型验证资源、模板和布局，不启动厂商服务。
- 载入原版按钮、开关、滑块、下拉框、复选框及单选框样式，验证换肤后的命令、双向绑定、
  可编辑下拉、弹出选项、不可用状态和键盘步进。
- EC 页面覆盖 640 / 800 / 1024 / 1440 DIP，检查重排、横向边界、交还按钮可达性，

- 保留原有入口的 15 组缩放测试，并验证局部遮罩的按钮保持 14 DIP、窄面板内完整显示。
- 结合原版托盘委托和本机任务计划程序只读检查，总计 39 项场景通过。
